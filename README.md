# TripAdvisor Clone

This project is a clone of the TripAdvisor website, built using HTML and CSS. It showcases a responsive design and basic web development skills by recreating the look and feel of TripAdvisor's user interface.

## Live Demo

Check out the live project here: [TripAdvisor Clone](https://santhoshkumaresansk.github.io/tripadvisor-clone/)

## Features

- Responsive homepage layout with a search bar  
- Navigation menu for exploring various sections  
- Basic styling for listings and reviews  

## Technologies Used

- **HTML**: For the structure and content  
- **CSS**: For styling and layout
